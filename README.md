# Hover

---

## 🎯 Objetivo

Projeto **Front-end** focado em testar **efeitos hover** utilizando **CSS**.  
Foi criado um layout com 4 **cards** interativos que reagem ao passar o mouse sobre eles, explorando animações e transformações.

---

## 🛠️ Ferramentas Utilizadas

- **HTML** – Estruturação básica dos cards e do layout.
- **CSS** – Estilização e implementação dos efeitos hover, animações e transformações.

---

## ✅ Conclusão

Esse projeto foi uma excelente oportunidade para aprender e praticar o uso de **efeitos hover** e **transformações** em CSS. Foi possível aplicar conceitos como **transições**, **transform** e **keyframes** para criar animações suaves, proporcionando uma interação visual interessante.

### Aprendizados:
- Como criar animações e transições no CSS.
- Manipulação de transformações (escala, rotação, etc.) nos elementos.
- Melhoria na usabilidade e estética de interfaces com interatividade.

O projeto foi simples, mas desafiador o suficiente para aprofundar meus conhecimentos em CSS, especialmente no uso de animações e efeitos interativos.
